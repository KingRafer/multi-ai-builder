# Push Full Game UI

File lengkap ada di lokal. Jalankan di terminal yang sudah login GitHub:

```bash
cd multi-ai-builder
# Salin index.html dan app.js dari folder multi-ai-office
cp /path/to/multi-ai-office/index.html .
cp /path/to/multi-ai-office/app.js .
git add index.html app.js
git commit -m "v3 PRO: full professional office UI"
git push origin main
```

Atau extract dari `multi-ai-office-v3.zip`.
