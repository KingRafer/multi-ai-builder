Deploy ke Vercel

Project sudah disiapkan dalam format siap Vercel.

  1. Download ZIP project (tombol di bawah)
  2. Extract, lalu push ke GitHub atau gunakan Vercel CLI
  3. Import di vercel.com/new
  4. Set environment variables (Supabase / DATABASE_URL jika ada)
  5. Deploy!
# Atau pakai CLI:
npx vercel --prod
