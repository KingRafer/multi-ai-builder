# MultiAI Office v3 PRO — Professional Game Mode

Aplikasi web multi-AI untuk membuat website & aplikasi profesional dengan **tampilan kantor raksasa game profesional**.

> **Status:** README + struktur repo sudah di GitHub. File `index.html` + `app.js` penuh (UI game) perlu di-upload manual sekali (lihat langkah di bawah) karena ukuran file besar.

## Fitur Visual Game

- Virtual Office Floor — floor grid, ambient light, particles
- Desk unit profesional — monitor animasi, status ring, glow
- Agent characters — bounce, speech bubble, XP popup, level up
- Phase chips — Plan → Design → Code → Review → QA
- Energy system + progress bar
- Mode Office / Classic switch
- Multi-agent: Nova, Luna, Kai, Rex, Aria
- Live Preview + Monaco Editor
- Export ZIP, Save, Deploy Vercel
- BYOK + Mode Demo

## Cara mendapatkan file penuh (pilih salah satu)

### Opsi A — Clone lalu ganti file (paling mudah)

```bash
git clone https://github.com/KingRafer/multi-ai-builder.git
cd multi-ai-builder
# Ganti index.html dan app.js dengan versi dari folder multi-ai-office
# (atau extract dari multi-ai-office-v3.zip)
git add index.html app.js README.md
git commit -m "v3 PRO: full game UI"
git push origin main
```

### Opsi B — Buka lokal tanpa push

```bash
npx serve .
# buka http://localhost:3000
```
